# touch-paint

タッチで描けるペイントツール。[touch-server](../touch-server) からタッチ入力を受け取り、
`/dev/fb0` フレームバッファに直接描画する。

## 必要環境

- `/dev/fb0` への書き込み権限（`video` グループ）
- `touch-server` が起動していること（Unix socket 経由で接続）
- CJK フォント（`fc-match "Noto Sans CJK JP"` が解決できること）

## 使い方

```sh
# 新規キャンバスで起動
touch-paint

# 既存 PNG を開いて描画
touch-paint path/to/image.png
```

## 操作（画面上部のツールバー）

- **8色スウォッチ**: ペンの色を選択
- **4つの丸**: ペンの太さを選択（消しゴム使用中でも変更できる）
- **消**: 消しゴム（背景色で描画）のオン/オフ
- **< / >**: undo / redo（1ストローク単位、最大20段）
- **保存**: PNG を保存
- **開く**: 起動時に指定した PNG を再ロード
- **x**: 終了

## 保存・読込について

- **保存先**: カレントディレクトリ下に `touch-paint-images/` フォルダを作り、
  その中に `touch-paint-<epoch>.png` として保存する。
  環境変数 `TOUCH_PAINT_DIR` を指定すると、そのディレクトリ自体を保存先にする。
- **開く**: フレームバッファ環境には GUI ファイルダイアログがないため、
  開くファイルは**起動時の CLI 引数で指定**する。ツールバーの「開く」は
  その引数で渡したファイルを再読み込みする。読み込んだ画像はアスペクト比を
  保ったままキャンバスにフィットし、余白は黒でレターボックスされる。

## 終了

ツールバーの **×** ボタン、または `Ctrl+C` / `SIGTERM`。
終了時にフレームバッファをクリアする。

## 環境変数

| 変数 | 既定値 | 説明 |
|------|--------|------|
| `TOUCH_SERVER_SOCK` | `$XDG_RUNTIME_DIR/touch-server.sock` | touch-server のソケットパス |
| `TOUCH_PAINT_DIR` | `./touch-paint-images/` | PNG の保存先フォルダ |
